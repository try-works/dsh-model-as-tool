<h2 id="taxonomy-20-public-labels-plus-org">Taxonomy (20 public labels, plus <code>ORG</code>)</h2>
<p><code>GIVEN_NAME</code>, <code>SURNAME</code>, <code>STREET_NAME</code>, <code>BUILDING_NUMBER</code>, <code>SECONDARY_ADDRESS</code>,
<code>CITY</code>, <code>STATE</code>, <code>ZIP_CODE</code>, <code>EMAIL</code>, <code>PHONE</code>, <code>CREDIT_CARD</code>, <code>BANK_ACCOUNT</code>,
<code>ROUTING_NUMBER</code>, <code>IP_ADDRESS</code>, <code>URL</code>, <code>GOVERNMENT_ID</code>, <code>PASSPORT</code>,
<code>DRIVERS_LICENSE</code>, <code>TAX_ID</code>, <code>SSN</code>.</p>
<p><code>ORG</code> (organisation / company name) is detected but <strong>not redacted by default</strong>:
a company is not a natural person. It exists so that <code>Silverfin</code>, <code>Odoo</code> or
<code>Visma Nova</code> are recognised as organisations instead of being mislabelled as a
<code>SURNAME</code>. Opt in by passing it explicitly in the SDK&#39;s <code>labels</code> option.</p>
<p>The deterministic layer additionally emits <code>IMEI</code> (device identifier), a
deterministic-only label outside the neural head.</p>
<h2 id="how-it-compares">How it compares</h2>
<p>Every system below was scored by the same harness on the same rows, each at its
own operating point, so the comparison measures the models rather than the
plumbing.</p>
<table><thead><tr><th>System</th><th>Recall</th><th>Precision</th><th>Size</th><th>Params</th></tr></thead><tbody><tr><td><strong>redact</strong></td><td><strong>88.8</strong></td><td><strong>99.6</strong></td><td><strong>11.6 MB</strong></td><td><strong>23M</strong></td></tr>
<tr><td>GLiNER-PII</td><td>91.1</td><td>90.4</td><td>2.3 GB</td><td>570M</td></tr>
<tr><td>Rampart</td><td>61.4</td><td>97.2</td><td>14.7 MB</td><td>18.5M</td></tr>
<tr><td>OpenAI privacy filter</td><td>60.2</td><td>93.5</td><td>3 GB</td><td>1.5B</td></tr></tbody></table>
<p><strong>Recall</strong> is the share of personal data fully masked (leak-safe), macro-averaged
over WikiANN, MultiNERD and a format-valid structured-PII set across 24 EU
languages. <strong>Precision</strong> is the share of masked spans that were really personal
data, on the structured set. Size is the Apple build; the Android and web build
is 24.5 MB.</p>
<p>Not masking ordinary words matters as much as catching real ones, because a
false positive corrupts the text a downstream model receives. On an 11,528-row
negative set across 27 languages, built to provoke exactly that (sentence-initial
capitals, ALL-CAPS input, month and weekday names, UI vocabulary, bare numbers,
company names), 94.1% of rows come back untouched.</p>
<h3 id="aws-comprehend-english-only">AWS Comprehend, English only</h3>
<p>Comprehend is the other service teams weigh, and it is not in the table above
because its PII API <strong>only accepts English</strong>, and every other language code is
refused outright, so there is no way to run it on the other 23. Scored on the
same English rows:</p>
<table><thead><tr><th>System</th><th>Names (WikiANN)</th><th>Names (MultiNERD)</th><th>Structured</th><th>English composite</th></tr></thead><tbody><tr><td>redact</td><td>69.5</td><td>94.9</td><td><strong>95.0</strong></td><td>86.5</td></tr>
<tr><td>AWS Comprehend</td><td><strong>84.3</strong></td><td><strong>98.5</strong></td><td>91.9</td><td><strong>91.6</strong></td></tr></tbody></table>
<p>Leak-safe recall; precision is the same for both (99.8 against 100.0). On English
names Comprehend is ahead of us. It also runs in the cloud, bills per call, and
covers one of the 27 languages listed below.</p>
