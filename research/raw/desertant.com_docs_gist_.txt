<h2 id="inputs-and-outputs">Inputs and outputs</h2>
<ul>
<li><strong>Input:</strong> a plain text string (title, or title + description). Best on short text like posts,
titles, and descriptions.</li>
<li><strong>Output:</strong> a probability over the 36 topics (<code>features [1, 8448]</code> → <code>topic_probs [1, 36]</code>); take
the top-k above the threshold in <code>gist_config.json</code>. Optimized for <strong>multi-label</strong> use: an item&#39;s
2-3 topics, optionally aggregated across a collection.</li>
</ul>
<h2 id="topics-and-standard-taxonomy">Topics and standard taxonomy</h2>
<p>The 36 topics map to two industry-standard taxonomies so gist output can be rolled up or joined
into existing systems: <strong>IAB Content Taxonomy 2.2</strong> (with each node&#39;s stable integer ID) and
<strong>Apple Podcasts categories</strong>. The full, machine-readable crosswalk ships in this repo as
<a href="https://huggingface.co/desert-ant-labs/gist/blob/v2.2.0/taxonomy_crosswalk.json"><code>taxonomy_crosswalk.json</code></a> (e.g. <code>law</code> → IAB <code>383</code> <em>News &amp; Politics ›
Law</em>, <code>crafts-hobbies</code> → IAB <code>248</code> <em>Arts and Crafts</em>, <code>finance</code> → IAB <code>391</code> <em>Personal Finance</em>).</p>
<p>Five topics have no dedicated IAB 2.2 node and are flagged as gist extensions
(<code>society-culture</code>, <code>creator-economy</code>, <code>outdoors-nature</code> map to a nearest parent; <code>history</code> and
<code>self-improvement</code> have no IAB node); <code>film-tv</code> is a roll-up of IAB <em>Movies</em> + <em>Television</em>.</p>
<h2 id="languages">Languages</h2>
<p>Topic tagging covers <strong>101 languages</strong>. A diverse 15-language spot check (across Latin, Cyrillic,
Arabic, CJK, Devanagari, Hebrew, Thai, and Greek scripts) gives <strong>88% top-3</strong>, with CJK, Arabic,
and Cyrillic scripts matching or beating the Latin ones.</p>
<h2 id="model-variants">Model variants</h2>
<p>Two builds of the same 36-topic model live in this repo:</p>
<table><thead><tr><th>Variant</th><th>Location</th><th>Size</th><th>Coverage</th></tr></thead><tbody><tr><td><strong>Multilingual</strong> (default)</td><td>repo root</td><td>~74 MB</td><td>101 languages</td></tr>
<tr><td><strong>English-only</strong></td><td><a href="https://huggingface.co/desert-ant-labs/gist/tree/v2.2.0/en"><code>en/</code></a></td><td><strong>~15 MB</strong></td><td>English / Latin script only</td></tr></tbody></table>
<p>The English build is the same model with a smaller embedding and tokenizer, so it is <strong>topic-identical to the multilingual model on English input</strong>. It does not cover non-Latin scripts (CJK, Arabic, Cyrillic, …); use it only when the input is reliably English/Latin. The Swift SDK selects it with <code>Gist(variant: .english)</code>. The JS and Kotlin SDKs currently load the multilingual build only: variant selection has to cross the shared native ABI, which has no slot for it yet.</p>
<h2 id="evaluation">Evaluation</h2>
<p>Recall on a held-out set of <strong>572 human-labeled real posts (36 topics)</strong>, zero-shot for the
LLMs and zero-shot classifiers. Embedding classifiers get a light logistic head; <strong>recall@3</strong> is the
product metric (downstream aggregation consumes the top few topics).</p>
<table><thead><tr><th>Model</th><th>Type</th><th>Size</th><th>recall@1</th><th>recall@3</th></tr></thead><tbody><tr><td>Qwen2.5-7B (cloud)</td><td>LLM zero-shot</td><td>server</td><td><strong>79%</strong></td><td>n/a</td></tr>
<tr><td>multilingual-e5-small + head</td><td>transformer embed</td><td>110 MB</td><td>74%</td><td>92%</td></tr>
<tr><td>bge-small-en + head</td><td>transformer embed</td><td>130 MB</td><td>71%</td><td>92%</td></tr>
<tr><td><strong>gist</strong></td><td><strong>on-device</strong></td><td><strong>~74 MB</strong></td><td><strong>71%</strong></td><td><strong>91%</strong></td></tr>
<tr><td>all-MiniLM-L6-v2 + head</td><td>transformer embed</td><td>90 MB</td><td>68%</td><td>90%</td></tr>
<tr><td>mDeBERTa-v3-mnli-xnli</td><td>zero-shot NLI</td><td>560 MB</td><td>50%</td><td>73%</td></tr>
<tr><td>GLiClass-base</td><td>zero-shot</td><td>400 MB</td><td>44%</td><td>65%</td></tr></tbody></table>
<p>gist is <strong>tied on recall@3</strong> with the best small models, at a fraction of the size and one on-device
pass, and it beats every zero-shot classifier decisively (they never learned the taxonomy or the
distribution). Only a 7B cloud LLM clearly leads on recall@1.</p>
