<h2 id="usage">Usage</h2>
<p>Apple only today. Create one detector and reuse it: the model loads on first
use, or earlier if you call <code>download</code>.</p>

16 kHz mono internally. <code>analyze(audioURL:)</code>, <code>analyze(bytes:)</code> for in-memory
audio, and <code>analyze(samples:sampleRate:)</code> for raw PCM are the other entry
points.</p>
<p><code>Options</code> trades recall against precision and drops spans that are too short.
<code>bias</code> is the threshold preset: <code>.precision</code> (0.75) for automatic cuts,
<code>.balanced</code> (0.65) by default, <code>.recall</code> (0.50) when you would rather review and
confirm than miss one.</p>

<a href="https://github.com/Desert-Ant-Labs/desert-ant-core/blob/v3.5.0/README.md#model-downloads-and-caching">model downloads and caching</a>.</p>
<h2 id="files">Files</h2>
<table><thead><tr><th>File</th><th>Format</th><th>Size</th><th>Use</th></tr></thead><tbody><tr><td><code>uhm.<wbr>mlmodelc/</code></td><td>Core ML fp16 (compiled)</td><td>~45 MB</td><td>iOS / macOS on-device</td></tr>
<tr><td><code>uhm-web-fp16.<wbr>onnx</code></td><td>ONNX fp16</td><td>~51 MB</td><td>Browser, server, Python (<code>onnxruntime</code>)</td></tr>
<tr><td><code>uhm.<wbr>onnx</code></td><td>ONNX fp32</td><td>~98 MB</td><td>Quantization-free reference</td></tr></tbody></table>
<p><code>uhm.mlmodelc/</code> is a compiled Core ML model directory. The Swift SDK downloads it with the Hugging Face Hub snapshot API, so only changed files are re-fetched on model updates.</p>
<p>The shipped model is a DistilHuBERT fine-tune. It is the smaller and more precise Uhm runtime model; the older HuBERT-base tier is no longer published.</p>
<h2 id="inputs-and-outputs">Inputs and outputs</h2>
<ul>
<li><strong>Input:</strong> 16 kHz mono audio, up to 30-second windows.</li>
<li><strong>Output:</strong> per-frame softmax over 6 classes, one prediction every 20 ms.</li>
<li><strong>Class indices:</strong> <code>0 = not_filler, 1 = uh, 2 = um, 3 = hmm, 4 = and, 5 = other</code>.</li>
</ul>
<p>Core ML input shape <code>(30, 1, 1, 16080)</code> float16 — the 30-second window pre-cut
into 30 overlapping tiles — and output <code>(1, 6, 1, 1499)</code> float16. The SDK builds
that layout for you; it exists because the Neural Engine caps every tensor axis
at 16384, and it is what lets the whole model run there. Requires iOS 17 /
macOS 14 or newer.</p>
<p>The ONNX artifacts keep the plain <code>(1, 480000)</code> float32 in, <code>(1, 1499, 6)</code> out
shape: the tiled layout is an Apple-silicon optimization and is slower on a GPU.</p>
<h2 id="performance">Performance</h2>
<p>Warm on-device runs on the published fp16 Core ML model:</p>
<table><thead><tr><th>Device</th><th>Realtime factor</th></tr></thead><tbody><tr><td>iPhone 17 Pro</td><td>~296×</td></tr>
<tr><td>iPhone 15 Pro</td><td>~169×</td></tr>
<tr><td>iPad Pro M4</td><td>~279×</td></tr></tbody></table>
<p>Realtime factor = audio duration ÷ analyze time; model load excluded.</p>
<p>Those are measured on the <em>previous</em> export. The current one runs every
operation on the Neural Engine and is 1.6× faster where it has been measured
(M1: 115× → 188× end to end), so these numbers are conservative until they are
re-measured on the devices themselves.</p>
<h2 id="limitations">Limitations</h2>
<ul>
<li>Trained on English; non-English performance is by acoustic transfer and has not been measured against per-language ground truth.</li>
<li>Best on podcast / meeting / talking-head audio. Heavy background music, laughter, or multi-speaker overlap degrades quality.</li>
<li>Type labels (<code>uh</code> / <code>um</code> / <code>hmm</code> / <code>and</code> / <code>other</code>) are secondary. Trust filler vs. not-filler more than the specific subtype.</li>
</ul>
<h2 id="built-on">Built on</h2>
<ul>
<li>Base architecture and pretrained weights: <a href="https://huggingface.co/ntu-spml/distilhubert"><code>ntu-spml/distilhubert</code></a>, a distilled variant of <a href="https://huggingface.co/facebook/hubert-base-ls960"><code>facebook/hubert-base-ls960</code></a>. Apache 2.0.</li>
<li>Public fine-tuning audio: <a href="https://huggingface.co/datasets/edinburghcstr/ami">AMI Meeting Corpus</a> (<code>edinburghcstr/ami</code>, IHM split). CC BY 4.0, Edinburgh CSTR.</li>
<li>Internal video content created by the Desert Ant Labs team.</li>
</ul>
