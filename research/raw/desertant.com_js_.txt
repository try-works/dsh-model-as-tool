        <h1 class="headline rise d2">On-device AI Models for JavaScript</h1>
        <div class="prose rise d3">
          <p class="lede">npm packages that run models in the browser and in Node, with TypeScript types included.</p>
          <p>The JavaScript and TypeScript packages run in Node and the browser, scoped under @desert-ant-labs on npm. The packages run the models through transformers.js, ONNX Runtime Web, or LiteRT.js.</p>
          <p>Everything runs locally, so data stays on the device. Install with npm and import with full TypeScript types.</p>
        </div>
